# 隐私权政策 / Privacy Policy

## 中文版

本扩展程序（AI 招聘助手）尊重并保护所有用户的隐私。本隐私政策旨在说明我们如何处理您的信息。

**1. 我们收集的信息**
本扩展会读取您当前浏览的招聘网站页面上的简历文本内容，以及您在设置中填写的第三方大模型 API Key、API 地址和职位描述（JD）。

**2. 我们如何使用信息**
- 您填写的 API Key、API 地址和 JD 仅保存在您本地浏览器的缓存（Storage）中，用于调用 AI 服务。
- 当您点击“分析当前候选人”时，提取的简历文本会连同您的 JD 一起，直接发送给您配置的第三方大模型接口（如 DeepSeek、OpenAI 等）以生成评估结果。

**3. 数据存储与共享**
本扩展程序的开发者**不拥有、不控制、也不存储**任何您的个人数据或候选人数据。我们没有任何后台服务器，绝不收集、出售或向任何第三方分享您的数据。

## English Version

This extension (AI Recruiter Assistant) respects and protects the privacy of all users. This privacy policy explains how we handle your information.

**1. Information We Process**
This extension reads the resume text on the recruitment website you are currently browsing, as well as the third-party LLM API Key, API URL, and Job Description (JD) you enter in the settings.

**2. How We Use Information**
- The API Key, API URL, and JD you enter are stored only in your local browser's storage to call the AI service.
- When you click "Analyze Current Candidate", the extracted resume text, along with your JD, is sent directly to the third-party LLM endpoint you configured (e.g., DeepSeek, OpenAI) to generate the evaluation result.

**3. Data Storage and Sharing**
The developer of this extension **does not own, control, or store** any of your personal data or candidate data. We do not have any backend servers and will never collect, sell, or share your data with any third parties.

If you have any questions, please contact: solu88867@gmail.com
